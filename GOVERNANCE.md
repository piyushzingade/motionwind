# Governance

Motionwind uses progressive maintainership.

1. **Contributor** — has merged a focused code, docs, recipe, or design change.
2. **Triager** — consistently reproduces reports, labels issues, and improves acceptance criteria.
3. **Package maintainer** — owns review, compatibility, documentation, and releases for one package or adapter.
4. **Core maintainer** — stewards the grammar, extension contracts, security, and cross-package releases.

Promotion is based on sustained work, sound judgment, inclusive collaboration,
and explicit acceptance—not commit count. Package maintainers are added to
CODEOWNERS. Core syntax or public extension changes require an RFC Discussion,
a compatibility plan, tests across official adapters, and approval from a core
maintainer. Maintainers disclose conflicts and recuse themselves when needed.
