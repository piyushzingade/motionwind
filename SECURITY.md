# Security policy

## Supported versions

Security fixes are provided for the latest stable release and the current
canary when a fix is being validated.

## Reporting

Do not open a public issue. Use GitHub's private vulnerability reporting at:

https://github.com/piyushzingade/motionwind/security/advisories/new

Include affected versions, impact, reproduction steps, and any suggested fix.
The maintainers will acknowledge the report within seven days and coordinate
disclosure after a patched release is available.
