# Support and compatibility

## Stable

- `motionwind-react`: React 18/19, Vite, Next.js webpack and Turbopack
- `motionwind-vue`: Vue 3 and Vite
- `motionwind-vanilla`: modern evergreen browsers using Motion for JavaScript
- `motionwind-core`: framework-independent grammar and extension contracts

## Beta

- `motionwind-react-native`: Expo and React Native with Reanimated 3/4

## Community

Svelte, Solid, Astro, alternate editors, and third-party adapters are supported
by their named package maintainers. An integration becomes official only after
it has compatibility fixtures, documentation, a maintainer, and two stable
releases.

Use GitHub Discussions for questions, Issues for confirmed bugs, and private
security advisories for vulnerabilities. The project follows active and
maintenance Node.js LTS lines; CI is the source of truth for exact versions.
