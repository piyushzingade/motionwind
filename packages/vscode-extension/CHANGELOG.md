# Changelog

## 2.0.0

### Major Changes

- Generate completions, hover help, and diagnostics from the shared Motionwind v2 syntax registry.
- Remove the extension's duplicate parser, types, constants, and classification lists.
- Report unsupported and invalid v2 syntax through shared parser diagnostics.

## 0.1.0

- Initial release
- Autocomplete for gesture prefixes, animatable properties, and config classes
- Hover documentation showing compiled Motion output
- Diagnostics for invalid `animate-*` classes
- Color decorators for hex color classes
