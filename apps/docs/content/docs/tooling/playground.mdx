## Full Studio

The embedded editor above is a compact version. Motionwind Studio adds a visual spring editor,
timeline, reduced-motion preview, responsive stages, reviewed recipes, share links, and exports
for React, Vue, JavaScript, and React Native. It lives on the marketing site at
[**Motionwind Studio**](https://web.motionwind.xyz/play).

## Using it in your own docs

The `<Playground>` component is available in MDX:

```mdx
<Playground
  initial="animate-hover:scale-110 animate-spring"
  tag="div"
  text="Hover me"
/>
```

It parses classes at runtime with the `mw.*` component and renders the compiled code with
`generateMotionCode` from `motionwind-react/tooling`.
