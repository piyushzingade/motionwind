---
title: "React (Next.js & Vite)"
description: "Set up motionwind in a React app. A build-time Babel transform rewrites your animate-* classes into Motion components — zero runtime, zero imports."
---

In React, motionwind is a **build-time Babel transform**. It scans your JSX for
static `className` strings containing `animate-*` tokens and rewrites those
elements into `motion.*` components with the right Motion props — so you write
plain elements and ship zero extra runtime.

## Install

```bash
npm install motionwind-react motion
```

`motion` is a peer dependency (React 18 or 19).

## Configure

### Next.js

Wrap your config with `withMotionwind`:

```ts
// next.config.mjs
import { withMotionwind } from "motionwind-react/next";

export default withMotionwind({
  // your existing config
});
```

### Vite

Add the plugin **before** `@vitejs/plugin-react`:

```ts
// vite.config.ts
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import { motionwind } from "motionwind-react/vite";

export default defineConfig({
  plugins: [motionwind(), react()],
});
```

## Write animations

Add `animate-*` classes to any lowercase HTML element — no import, no `"use client"`:

<Demo title="Hover & tap">
  <button className="px-6 py-3 bg-fd-primary text-fd-primary-foreground rounded-xl font-medium cursor-pointer animate-hover:scale-110 animate-tap:scale-90 animate-spring">
    Click me
  </button>
</Demo>

```tsx
<button className="animate-hover:scale-110 animate-tap:scale-90 animate-spring">
  Click me
</button>
```

## Good to know

- **Static strings only.** The transform reads literal `className` strings. For
  dynamic or conditional classes, use the `mw.*` runtime components
  (`import { mw } from "motionwind-react"`).
- **`"use client"` is automatic.** In the App Router, any transformed file gets
  `"use client"` and the `motion/react` import injected for you.
- **Lowercase tags only.** `<div>`/`<button>` are transformed; custom components
  (`<Card>`) are skipped — apply classes to an element inside instead.
