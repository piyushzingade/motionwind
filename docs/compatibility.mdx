# Compatibility Matrix

Motionwind v2 treats compatibility as executable data. CI validates this table
against each adapter's exported capability contract and installs every starter
from packed npm artifacts.

## What the statuses mean

### Pass

The feature is fully supported. CI runs automated tests against the actual
published package. The adapter compiles `animate-*` classes into the correct
Motion or platform API calls.

### Warning

The adapter **detects** the syntax and **explains** the capability gap. It
never silently ignores unsupported classes. You can still use the feature, but
you'll need to use the direct Motion or platform API for full control.

Example: Vue + Vite scroll animations show a warning because the template
transform doesn't fully support scroll-linked animations. Use
`useScroll()` from Motion directly.

### Beta

The feature works but has known limitations or gaps. It's tested but not
guaranteed to be stable. Use in production with caution.

Example: React Native gesture support is in beta — basic hover, tap, and focus
work, but advanced gesture recognizers may need direct Reanimated APIs.

### Unsupported

The adapter does not implement this feature. The `animate-*` syntax is
detected, but no output is generated. Use the direct platform API instead.

Example: Vanilla JavaScript doesn't support layout animations because it
doesn't have a component model. Use Motion's `layout` prop directly.

## The golden suite

CI runs these tests against every framework:

- Hover, tap, focus, and keyboard access
- Enter/exit transitions
- In-view (scroll-triggered) animations
- Scroll-linked animations
- Drag gestures
- Layout animations
- Variants and stagger
- SVG path drawing
- Presets
- Strict diagnostics
- Reduced motion policy
- SSR output and hydration
- Source maps
- Tree shaking
- Bundle size budgets

Framework jobs install and build from the exact tarballs intended for npm. Browser
scenarios assert declared scale values (not just checking for a transform) and
fail on runtime, console, hydration, or security errors.

## React Native status

React Native is in beta. v2 supports:

- Shared parser and presets
- Plugins and configuration
- Timing adaptation
- Variants and scroll context
- Reduced motion

Not yet supported (use direct APIs):

- Drag gestures
- Layout transitions
- In-view orchestration
- SVG animations

These produce actionable warnings, not silent failures.
