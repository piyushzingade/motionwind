# Motionwind starters

These installable fixtures are both copyable starters and compatibility smoke
projects. Each keeps one animated interaction, the framework integration, and
the minimum dependencies required by its adapter.

- `next` — Next.js App Router
- `react-vite` — React with Vite
- `vue-vite` — Vue 3 with Vite
- `nuxt` — Nuxt with the Vue runtime adapter and SSR
- `vanilla` — plain TypeScript and HTML
- `expo` — React Native with Expo and Reanimated

Copy a directory, install dependencies with your package manager, and run the
documented `dev` command. CI validates packed Motionwind releases against the
same integration shapes before publication.
