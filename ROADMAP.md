# Motionwind roadmap

## Adoption and trust

- Shared grammar and generated tooling metadata
- Reliable init, doctor, migration, presets, releases, and compatibility fixtures
- Stable React, Vue, and JavaScript adapters; beta React Native adapter

## Extensible platform

- Typed configuration, named tokens, presets, plugins, adapter capabilities
- Shared compiler integrations and community-owned framework adapters
- Public deprecation and promotion policies

## Creator ecosystem

- Motionwind Studio with multi-target export and reduced-motion preview
- GitHub-reviewed recipe registry and CLI installation
- Registry-generated language and AI tools

Roadmap review happens in a monthly GitHub Discussion. Quarterly compatibility
reports record releases, package support, first-time contributors, external
maintainers, recipes, and adapter adoption. Milestone exit criteria—not dates—
determine when the project advances.
